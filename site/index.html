The hub

Walk into a portal.
You're in the game.

Every server is a lobby: a glowing hall with a portal for each game. Each one shows what it is, how many people are playing, and whether a round is open or already running. Step through and you're there — no menus, no waiting rooms.

  • Live player counts and round status on every portal
  • Party up with /party invite — the leader walks in, everyone follows
  • Full game? The portal tells you instead of kicking you
  • Back to the lobby any time with /lobby or the pause menu

Phone & PC

Made for thumbs.
Tuned for any screen.

One link, no download. Touch controls with an analog stick, fire/reload/swap buttons and a full-screen map — plus keyboard and mouse on desktop.

  • Adaptive quality — detects your device, then lowers resolution and effects on the fly if frames slip, and gives them back when there's headroom
  • Ultra mode for strong GPUs: shadows, ambient occlusion, bloom, light shafts
  • Live performance stats overlay: FPS, 1% lows, frame graph, ping, draw calls
  • Fast, flicker-free world loading with chunk streaming

Run your own

Your server, your rules

Voxel Realms ships with its own game server and admin panel. It runs on a laptop — or a Raspberry Pi. One click sets up the whole hub, and you choose which games get a portal.

# start a server
npm install && npm run build && npm start
# then: Admin → Games → Set up game hub
  • Toggle any game's portal on or off per server
  • Live dashboard: players, TPS, CPU, memory, logs
  • Bans, allowlist, operators, maintenance mode, backups & restore
  • Mobile-friendly admin panel with built-in help

Questions

Good to know

Is it free? Do I need to install anything?

It's free and runs entirely in your browser — open the link and play. No account, no download.

What if nobody else is online?

Bots join automatically whenever at least one person is in a game, so you can always get a match. Real players replace bots as they arrive.

It runs slowly on my phone. What can I do?

The game picks settings for your device and adapts while you play. You can also choose the Low preset, or press F3 / tap the coordinates to see exactly what's slow.

Can I play with friends privately?

Yes — use /create to spin up a private match with as many bots as you like, then share the code. Or form a /party and walk into any portal together.

Can I host my own server and pick the games?

Yes. Start the server, open /admin/, hit Set up game hub, and switch portals on or off per game. It also runs on a Raspberry Pi.

Does my singleplayer world save?

Worlds save automatically in your browser. Multiplayer worlds are saved by the server with automatic backups.
