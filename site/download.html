Get the app

The same game, in its own window. Pick a server, press Play. The app always loads the server's current version, so there is nothing to update.

First run

  1. Open the app. Your server is listed with a green dot when it is online.
  2. Press Play. To add another server, type its address and press Add.
  3. Desktop: Game → Switch server (Ctrl/Cmd+Shift+S) brings the list back; F11 toggles fullscreen.
